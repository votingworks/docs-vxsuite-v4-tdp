# Guidance for Test Labs

This page covers guidance for test labs that is not relevant to election workers.

## Power Cycling

While test labs may run machines for long periods of time, as required for tests like the 104-hour continuous operations test, VotingWorks recommends powering down machines every couple of days. Rebooting a machine triggers necessary log file compression and rotation to save disk space. While some log files are compressed and rotated automatically on a daily basis, others are not in order to maintain the highest possible fidelity and are only compressed and rotated on reboot.
